# NCSNA Delivery Checklist

## Before starting

- [ ] Confirm NCSNA approved audit or trial
- [ ] Confirm payment if audit-first
- [ ] Save eBay store link
- [ ] Save 3–10 priority listing links
- [ ] Save baseline sales number
- [ ] Confirm the primary goal

## Audit work

- [ ] Review listing titles
- [ ] Review item specifics / product details
- [ ] Review photos / presentation
- [ ] Review descriptions
- [ ] Review pricing and shipping clarity
- [ ] Review store trust cues
- [ ] Note obvious competitor or category gaps
- [ ] Pick top 3 priorities
- [ ] Recommend one next step only

## Delivery

- [ ] Clean up audit notes
- [ ] Keep recommendations high-level
- [ ] Do not include full implementation rewrites
- [ ] Send summary to NCSNA
- [ ] Offer Store Cleanup or 60-day trial if justified
- [ ] Update baseline tracker

## If trial starts

- [ ] Create 60-day trial calendar
- [ ] Document baseline sales
- [ ] Define what counts toward sales above baseline
- [ ] Confirm monthly base and performance share
- [ ] Define reporting cadence
- [ ] Avoid taking on daily customer support
