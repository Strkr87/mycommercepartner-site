# NCSNA Intake Checklist

## Required before audit starts

- [ ] eBay store link
- [ ] 3–10 priority eBay listing links
- [ ] current monthly eBay sales baseline
- [ ] products/categories they most want to move
- [ ] any known listing issues they already see
- [ ] decision: audit-first or 60-day trial-first
- [ ] best contact person for approvals

## Helpful but optional

- [ ] screenshots of seller dashboard trends
- [ ] top-selling products
- [ ] slow-moving products
- [ ] return/refund concerns
- [ ] inventory constraints
- [ ] competitor examples they like

## Do not request unless needed

- eBay login access
- customer message access
- payment information
- sensitive business documents

For an audit, listing/store links are enough to begin.
